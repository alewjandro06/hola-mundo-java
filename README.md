# Prácticas de Java – Fundamentos de Programación

Repositorio donde estoy desarrollando mis habilidades en programación desde cero, enfocado en lógica y fundamentos en Java.

## Tecnologías utilizadas

* Java
* IntelliJ IDEA

## Temas que he trabajado

* Variables y tipos de datos
* Entrada de datos con Scanner
* Condicionales (if, else, anidados)
* Ciclos (while y for)

## Algunos ejercicios

* Sistema de becas
* Login con intentos
* Clasificación de edades

## Objetivo

Construir una base sólida en programación para avanzar a Programación Orientada a Objetos y desarrollo profesional.
